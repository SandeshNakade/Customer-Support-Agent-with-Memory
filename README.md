# Customer Support Agent with Memory

## Current codebase

This repository currently incorporates the ScoutifyAI application: an
AI-powered, personalized job-search service built with FastAPI and Streamlit.
It uses OpenAI, Pinecone, Supabase, and RapidAPI credentials supplied through
environment variables.
